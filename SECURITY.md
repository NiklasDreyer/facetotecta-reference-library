# Security and data protection

This repository contains analysis code only. Raw sequencing data, reference databases and results are excluded by `.gitignore` and are not tracked.

- **Do not commit** credentials, cluster account details beyond the SLURM account name, or unpublished data from collaborators.
- **Sample permits and locality details** for sensitive sites should not be committed. Keep them in `config/specimens.tsv` only if they may be shared.

To report a security concern, email dreyer@snm.ku.dk rather than opening a public issue.
